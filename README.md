# Islamic Guidance AI

An AI-powered application for providing Islamic guidance based on Quran and Hadith.

## Overview
This project aims to leverage Artificial Intelligence to help users find guidance from Islamic scriptures (Quran and Hadith) relevant to their questions or problems.

## Features
- **Natural Language Understanding**: Users can ask questions in natural language.
- **Quran & Hadith Search**: The system searches for relevant verses and hadiths.
- **Contextual Guidance**: AI synthesizes the information to provide compassionate and accurate guidance.

## Setup
1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    pip install -r requirements.txt
    ```
3.  Set up environment variables in `.env`.
4.  Run the application.

## Project Structure
- `api_tester.py`: Script for testing API interactions.
- `api_parsers.py`: Parsers for Quran and Hadith API responses.
- `src/`: Source code for the frontend application.
